ASHI TRADERS Billing App

FILES
- index.html: billing software
- manifest.json, sw.js, icon.svg: installable PWA support

HOW TO USE
1. Upload all four files to the same folder on an HTTPS website (GitHub Pages is free).
2. Open the HTTPS website in Chrome on Android.
3. Open Chrome menu (⋮) > Install app / Add to Home screen.
4. Use the app offline after it has loaded once.

BILLING
- Seller details are editable and start with the details visible in the supplied sample invoice.
- Add/remove item rows; amount and GST totals calculate automatically.
- GST mode can be CGST+SGST, IGST, or No GST. Rates are editable.
- PDF / Print opens Android/Chrome print dialog. Choose Save as PDF.
- Saved bills are stored in this browser on this device. Export JSON backup regularly.

IMPORTANT
This is a client-side billing tool, not a GST filing or e-invoice portal. Confirm GST rates, tax treatment, invoice particulars and statutory compliance with your accountant / official GST guidance. No data is sent to a server.
